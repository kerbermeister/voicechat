## Изменения

- AppDelegate возвращает штатное решение Flutter при Cmd+Q. CallController
  обрабатывает exit request и ждёт общей teardown future не более5 секунд.
  Закрытие окна отдельно вызывает end, фоновые уведомления остаются возможны.
- DirectCall.close идемпотентен, повторный вызов ждёт ту же очистку. Hangup
  отправляется параллельно медиа; SDK delegate не ждёт сетевую запись истории.
- Завершённая сессия не оживает после позднего SDP/ICE. Принятие сериализовано;
  поздний getUserMedia освобождается. Кандидаты применяются после remote SDP,
  включая время ожидания answer. Ошибка отправки сохраняет копию очереди ICE.
  Connected/Completed отменяют deadline; начальное подключение ограничено30с,
  потеря транспорта15с с возможностью восстановления.
- Реальный Mac-тест обнаружил MissingPluginException enableSpeakerphone:
  SDK вызывал мобильный метод на desktop. Ограничен Android/iOS.
- macOS14+: SCContentSharingPicker, выбранный SCContentFilter → SCStream →
  RTCVideoSource. Звук экрана выключен, первый кадр обязателен, остановка и
  отмена освобождают native stream. Legacy CG preflight не блокирует picker.
  macOS12/13 сохраняют прежний путь; sandbox/подписи/Keychain не ослабляются.

## Выход на всех клиентах и возвращение в группу

- POST `/call/active` проверяет текущую Matrix-сессию, членство, шифрование
  комнаты и запрет личной комнаты. Возвращает только session/video/count;
  не выдаёт токены медиа/ключи/список устройств и не продлевает допуски.
- Открытая группа проверяется каждые5с и при возврате приложения. Плашка находится
  под её заголовком, не в списке всех чатов. Ошибка сети сохраняет последнее
  подтверждение максимум30с. Присоединение использует существующую session;
  `join_existing` атомарно запрещает возрождать уже завершённую сессию.
- Закрытие группового звонка отправляет leave параллельно очистке медиа.
  Присутствующие участники продолжают в том же session с обязательной сменой
  защищённого media generation. Старое приглашение истекает через45с;
  присоединение после этого доступно по плашке.
- Android: `onTaskRemoved` и фактическое завершение Activity посылают общий end;
  service ждёт callback максимум5с. Обычный Home/minimize не считается закрытием.
- Web: pagehide/freeze вызывают завершение. Малые terminal-запросы используют
  fetch keepalive только после проверки доверенного маршрута, с Bearer,
  без cookies/redirect, сохраняя Matrix ciphertext. Переключение вкладки не
  завершает звонок. При kill/остановке JS доставка не гарантируется: direct
  завершается по ICE disconnect deadline, group lease истекает за30с.
- iPhone PWA/Safari не гарантируют pagehide при уничтожении процесса. Это
  ограничение покрывается обнаружением потери соединения, не обещанием
  синхронного уведомления. Нативных Windows/Linux runners в репозитории нет.
