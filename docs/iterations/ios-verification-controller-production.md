# Продолжение проверки устройства без кадров UI — 25 октября 2026

После первой выкладки пользователь сообщил, что Safari всё ещё ждёт начало
сверки, а webapp ждёт ответ даже через 30–60 секунд. Поэтому сценарий iPhone
не считается исправленным по результатам первого релиза.

В `main`, на VPS и локальном стенде опубликован
`422ea4916d3693f2ea19afdea68c897a19805de5`.
[Build and deploy #22](https://github.com/kerbermeister/voicechat/actions/runs/40187018844)
завершился успешно за 4 мин 16 с, режим `web`.

Автоматическое продолжение own-device проверки перенесено из callback отрисовки
диалога в `DeviceVerifications`. Полученный ready может начать SAS без диалога
и кадров интерфейса. Шаги выполняются последовательно; отменённый запрос не
продолжается, сетевой сбой не запускает бесконечный повтор. Принятие входящего
запроса, сравнение и подтверждение эмодзи остаются явными действиями.

Четыре новых теста не используют widget/pump. Два падают на опубликованном
контроллере c57e2fa, все проходят после переноса. Полная клиентская регрессия:
215 passed, 3 optional skipped; анализатор без замечаний. Собраны release web
и debug APK arm64; CI также прошёл серверные и клиентские проверки.

До изменения UI два настоящих SDK-клиента с отдельными SQLite-хранилищами,
vodozemac и локальным Synapse получили одинаковые SAS и семь эмодзи — и при
непрерывной работе, и при поочерёдном abort/resume sync. В опубликованной
версии c57e2fa два web-клиента во внутреннем браузере дошли до сравнения,
на новом отображались семь эмодзи. Проверка отменена до выдачи доверия.
Созданные для этих проверок аккаунты на локальном сервере и VPS деактивированы.
Это отдельные проверки протокола/desktop UI, а не приёмка iPhone.

Web-only guard подтвердил прежний backend fingerprint. Control digest,
ID/StartedAt/RestartCount всех backend-контейнеров остались прежними.
Manifest и фактический web digest соответствуют 422ea49. Публичный JS совпал
с контейнером по SHA-256. App/API/worker/WASM отвечают 200, приватные маршруты
— 404; no-cache, COOP и COEP сохранены. База контактов: integrity `ok`, 20 записей;
screen flag `1` сохранён. Rollback pointer указывает на c57e2fa, каталог сохранён.

Локальный `http://localhost:7362/` отдаёт эту же ревизию с локальными endpoints;
серверный JS совпадает с новой локальной сборкой. Crypto assets переиспользованы
из проверенного c57e2fa: их входы в этой правке не менялись.
