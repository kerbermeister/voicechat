# Компактная сверка устройств — 25 октября 2026

Причина последнего сообщения о невидимых эмодзи и числах подтверждена
пользователем: после прокрутки диалога они появились. Два теста исходной
компоновки воспроизводят выход SAS ниже видимой области мобильного экрана.

В main, на VPS и локальном стенде опубликован
`f97e10c2bd66a92747fb3554bf108ea032e2f743`.
[Build and deploy #24](https://github.com/kerbermeister/voicechat/actions/runs/40190849015)
успешен в режиме web; backend-контейнеры не перезапускались.

Сначала показаны переключатель и коды, затем инструкция и идентификаторы.
Переход от запроса к SAS сбрасывает прокрутку. Две кнопки сравнения стоят рядом,
имеют область касания не менее 48; при увеличенном тексте переносятся целиком.
Отмена на этапе SAS доступна через крестик в шапке, её действие проверено тестом.

По явно подтверждённому решению пользователя показываются первые шесть эмодзи
в одной строке: визуальная сверка сокращена с 42 до 36 бит. Числа, MAC и проверка
ключей прежние. Для клиентов со стандартными семью символами следует использовать
числовой SAS в обоих окнах. Согласование и обоснование записаны в
[задаче](../tasks/12-ios-device-verification.md).

219 клиентских тестов прошли, 3 optional пропущены; анализатор без замечаний.
Собраны release web и debug APK arm64. Тесты проверяют загруженные RawImage,
геометрию всех шести символов и чисел внутри viewport, в том числе при тексте
150%. Это сильнее прежней проверки наличия Text/Image в дереве виджетов.

Публичный JS совпадает с контейнером, commit/digests и rollback pointer проверены.
Backend fingerprint и control digest прежние, ID/StartedAt/RestartCount серверов
не изменились. API здоровы; no-cache, COOP и COEP сохранены. Локальный JS совпадает
со сборкой и содержит локальные endpoints; предыдущая сборка сохранена.
