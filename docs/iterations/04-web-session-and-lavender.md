# Итерация 4: сохранение веб-входа и Lavender Soft

21 октября 2026. Владелец переключил приоритет с SAS/QR и серверного управления звонками на удобство веб-клиента. Отложенные задачи остаются в [TODO](../implementation-status.md).

## Вход и обновление страницы

Раньше Matrix-сессия и история уже сохранялись в зашифрованной IndexedDB, но экран не восстанавливал выбранный профиль, а ключ разблокировки терялся при reload. Теперь сохраняются имя аккаунта, профиль и адреса подключения; вкладка хранит собственный выбор аккаунта независимо от других вкладок; пароль аккаунта и локальная фраза не сохраняются. Последний открытый чат возвращается после входа, если пользователь всё ещё состоит в нём.

По явному выбору владельца включено «Сохранять вход в этой вкладке». Можно отключить при входе.

| Действие | Результат |
| --- | --- |
| Обновить открытую вкладку | Восстанавливаются тот же Matrix device/session и выбранная переписка, без ввода паролей |
| Открыть профиль без сохранённой разблокировки | Нужна локальная фраза; пароль аккаунта повторно не требуется для действующей сессии |
| Заблокировать | Закрываются звонок, клиент и ключи, удаляется ключ возобновления вкладки |
| Обновить после блокировки | Снова запрашивается локальная фраза |
| Выйти | Серверная Matrix-сессия отзывается; локальные ключи, история и запомненный аккаунт удаляются после успешного выхода |

Старый профиль не мигрирует и не сбрасывается. После установки этой версии нужно один раз открыть его обычным способом, чтобы сохранить параметры входа.

### Компромисс сохранения разблокировки

С включённым сохранением вкладка держит 256-битный AES-ключ в `sessionStorage`, чтобы импортировать его после reload и проверить по существующему AES-GCM заголовку. Рабочий `CryptoKey` остаётся non-exportable. PBKDF2-SHA-256/600000, соль, AAD, формат записей и проверка повреждений не меняются; пароль и фраза не попадают в `localStorage`/`sessionStorage`. SDK и тестовый стенд по умолчанию не сохраняют разблокировку — это опция обычного клиента.

Это осознанно более слабая защита от доступа к локальному профилю браузера: ключ доступен JavaScript того же origin и браузер может сохранить сессию на диск, восстановить закрытую вкладку или скопировать её при дублировании. Нельзя обещать, что закрытие вкладки гарантированно уничтожает все копии. Для явного завершения разблокировки текущей вкладки используется «Заблокировать»; для строгого режима опцию сохранения надо отключить. Защита от XSS/компрометации origin не обеспечивается ни этим механизмом, ни открытой вкладкой с ключом только в памяти. Ключ возобновления не отправляется серверу.

## Интерфейс

Основа — [выбранный Lavender Soft](../design/README.md): лавандовая градиентная область, коралловая шапка чата, светлые поверхности, мягкие аватары и асимметричные пузыри сообщений. Ocean Calm и Midnight используют ту же компоновку и переключаются в настройках.

- Стартовый экран с иллюстрацией, отдельной формой входа/разблокировки и свёрнутыми параметрами подключения. На небольшом экране вся форма прокручивается вместе с приветствием.
- Слева две вкладки: «Люди» для Matrix DM и «Группы» для групповых комнат. Это существующие переписки и приглашения, а не весь серверный каталог. Поиск в списке фильтрует свои чаты; «Найти человека» открывает отдельный каталог.
- Список показывает реальное имя комнаты/собеседника, превью последнего события, время и непрочитанные. Статус берётся из Matrix presence; если данных нет, показано «Статус неизвестен». Статусы не выдумываются.
- Создание группы и поиск человека открываются отдельно. Переписка имеет собственную шапку, звонок, настройки участников, поиск истории и область ввода.
- Общие настройки вынесены в отдельное окно: темы, устройства, сверка отпечатков, ключ восстановления, backup, блокировка и выход.
- На десктопе одновременно видны список и переписка; на телефоне — один экран с возвратом назад. Выбранная вкладка сохраняется при возврате и смене ширины.
- Короткие переходы появления/исчезновения и смены вкладок; нет бесконечных фоновых анимаций. Основные переходы учитывают системное отключение анимаций. Время отображается в 24-часовом формате.

## Проверка

Перечисленные ниже проверки завершились успешно на финальной локальной сборке.

- `flutter analyze`; `flutter test` — 18 тестов, включая восстановление несекретных параметров и разделение людей/групп, превью, presence и непрочитанные.
- `prototype/test_web_vault.cjs` — настоящее WebCrypto в Chrome: шифрование, AAD, повреждения, неверная фраза, сохранение данных, reload, возобновление вкладки, opt-out, совместимость старого формата vault, повреждение ключа возобновления, изоляция аккаунтов вкладок и удаление ключа при блокировке.
- `prototype/check_ui.cjs` — реальный локальный Synapse, свежий тестовый аккаунт: вход, группы/каталог/личная переписка, текст/изображение/голосовое, правка/реакция, reload с тем же device ID, узкий экран, настройки и lock/reload/unlock/logout.
- `prototype/check_signup_ui.cjs` — регистрация через локальный Mailpit и выход через новые настройки.
- Обычные web/debug APK собираются из `lib/main.dart`. Полный лабораторный сценарий звонков в этой итерации не повторяется: протоколы звонков не менялись.
