# Личные macOS-обновления — 26 октября 2026

Добавлен явный `--personal` режим упаковщика. Он сохраняет проверки AOT, arm64,
macOS 12, ad-hoc подписи приложения, подписей архива/feed и чистой ревизии.
Обычный `--release` по-прежнему требует Developer ID и нотарификацию.
Исправлена отсутствовавшая настройка `SUVerifyUpdateBeforeExtraction`, обязательная
для используемого `SURequireSignedFeed`.

Проверки: 8 Python macOS-тестов; Flutter analyze без замечаний; 6 тестов
`test/app_update_test.dart`. Настоящие release-сборки 3 и 4 успешно собраны на Mac.
Кандидат 4 прошёл проверку native binaries, подпись ZIP и signed appcast.

Первую сборку 3 установили вручную после закрытия прежнего приложения и
локального резервирования `.app`, Documents и Preferences. Владелец разрешил
системный запрос Keychain; прежний аккаунт и старые сообщения восстановились.
Проверен точный ZIP сборки 4: распакован, запущен, подтверждены версия, тот же
аккаунт/устройство и прежние сообщения. Схема БД и код хранения между 3 и 4 одинаковы.

После приёмки кандидат опубликован существующим `publish_macos.py` на VPS.
Через настоящий интерфейс установленной сборки 3 выполнены «Проверить обновления»
и «Скачать и установить». Sparkle загрузил пакет по HTTPS, установил его и
перезапустил приложение. В интерфейсе подтверждена версия 1.2.0 (сборка 4),
тот же идентификатор устройства и отображение прежних сообщений без нового входа.
Повторная проверка сообщает «Совместимых обновлений нет». Все обычные файлы
установленной `.app` совпадают по SHA-256 с распакованным принятым ZIP.

Опубликовано: https://univc.duckdns.org/updates/macos/appcast.xml (`no-cache`).
ZIP и DMG в `/updates/macos/4/` отдаются immutable; все три публичных файла
проверены по SHA-256 manifest. Серверные службы не пересобирались/не перезапускались.
Source commit кандидата: `690b841bfda312e68d0656cadfcce736e0232918`.
ZIP SHA-256: `914499816e95f2e7324505ae014a21a6978592501e17f390f90fd59e055a995e`.

Проверка относится к этому Mac и видимой старой переписке, не ко всей истории
каждого чата. Другие версии macOS, отзыв дефектного релиза и восстановление после
потери ключа в этой итерации не проверялись. Пользовательский профиль не удалялся,
секретные ключи аккаунта не экспортировались.
