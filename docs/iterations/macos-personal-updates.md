# Личные macOS-обновления — 26 октября 2026

Добавлен явный `--personal` режим упаковщика. Он сохраняет проверки AOT, arm64,
macOS 12, ad-hoc подписи приложения, подписей архива/feed и чистой ревизии.
Обычный `--release` по-прежнему требует Developer ID и нотарификацию.
Исправлена отсутствовавшая настройка `SUVerifyUpdateBeforeExtraction`, обязательная
для используемого `SURequireSignedFeed`.

Проверки: 8 Python macOS-тестов; Flutter analyze без замечаний; 6 тестов
`test/app_update_test.dart`. Настоящие release-сборки 3 и 4 успешно собраны на Mac.
Кандидат 4 прошёл проверку native binaries, подпись ZIP и signed appcast.

Первая сборка 3 установлена вручную после закрытия прежнего приложения и
локального резервирования `.app`, Documents и Preferences. Исходная версия имела
ad-hoc подпись и открытый аккаунт с отображаемой историей. Код хранения и bundle ID
не менялись. После запуска новой сборки securityd зарегистрировал запрос доступа
к Keychain для `/Applications/VoiceChat.app`; требуется действие владельца Mac.
До его завершения сохранность доступа к аккаунту/истории не подтверждена.

Публикация кандидата 4 на VPS и фактическое обновление 3 → 4 пока НЕ выполнены.
Канал VPS существует, но appcast отсутствует. Приёмка точного ZIP и восстановление
старых сообщений должны предшествовать его продвижению. Не выставлять фиктивный
MACOS_ACCEPTED_SHA256 ради обхода проверки.

Ключ Sparkle хранится в login Keychain, account `voicechat-personal`. Локальная
копия и конфигурация находятся в `~/Library/Application Support/VoiceChatRelease`
с ограниченными правами; секреты не включены в Git/пакеты и не отправлялись на VPS.
Внешняя защищённая резервная копия ключа пока не подтверждена.
