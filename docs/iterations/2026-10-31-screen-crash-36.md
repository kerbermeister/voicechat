# Исправление краша демонстрации экрана — 36

## Наблюдение и причина

31.10.2026 пользователь проверил опубликованный Mac1.15.3(35): выбор всего
экрана завершил приложение, у собеседника звонок остался открытым.
Санитизированный разбор локального crash report: EXC_BAD_ACCESS/SIGSEGV,
PC=0, LR в flutter_webrtc+0x19e84, FlutterWebRTCPlugin.m:953, вызов
CapturerStopHandler при trackDispose. Дизассемблирование подтверждает вызов
нулевого указателя block invoke. Swift closure в NSMutableDictionary была
стёрта до Any; исправление явно задаёт Objective-C block ABI и escaping completion.
Сырые отчёт, пути профиля, содержимое чатов и идентификаторы аккаунта не включены.

## Изменения

- Проверка реальных SDK trackDispose и streamDispose в XCTest, без выбора
  пользовательского экрана и без захвата/отправки его содержимого.
- Обработка SCFrameStatus.started и complete с валидным pixel buffer;
  idle/blank/suspended/stopped не подтверждают начало показа.
- Удалено второе ожидание кадра только после успешного native picker start:
  он уже ждёт настоящий пиксельный кадр. Legacy macOS12/13 сохраняет проверку.
- Общий Matrix-клиент отслеживает также состояние DTLS/peer connection:
  closed/failed завершают звонок, disconnected даёт15 секунд на восстановление.
  Поздний connected не воскрешает завершённый вызов.

## Проверки и выпуск

Проверки финального кода:
- Flutter:473 PASS,4 пропуска; analyzer PASS.
- Python:772 теста,3 пропуска, PASS. Первый прогон остановил реальный guard
  свободного места (<2GiB); повтор прошёл после удаления собственных
  регенерируемых промежуточных файлов. Guard не ослаблялся.
- Release XCTest на реальном Mac15.3.1:2 PASS. Это тест SDK и валидатора
  sample buffer; не проверка системного выбора экрана или передачи собеседнику.
- Обычный web lib/main.dart, production config, закреплённые crypto assets:
  сборка PASS; публикация не выполнена.
- Mac36 построен из чистого28ba8a9172f3a6a14eb0b30b18de85ff9755a1e3.
  Чистый release bundle не содержит XCTest/тестовых плагинов.
  ZIP и DMG совпали по285 файлам/ссылкам, codesign PASS.
- Точный подписанный кандидат36 открыл прежний аккаунт и устройство;
  один контрольный фрагмент старой расшифрованной истории совпал, About36 PASS.
- Mac36 опубликован штатным издателем; HTTPS200 и SHA-256 совпали.
  Feed no-cache; неизменяемые ZIP/DMG кешируются. Managed pointer не менялся.
  Штатная установка35→36 завершена. Установленные285 файлов/ссылок
  точно совпали с ZIP, codesign PASS, процесс запущен из /Applications.
  About1.15.4(36), прежний аккаунт/устройство и контрольный фрагмент старой
  расшифрованной истории подтверждены; приложение оставлено в исходном чате.

Полный показ Mac→другое устройство и завершение после kill/crash на телефонах
не подтверждены. Чёрный экран и зависший разговор нельзя объявлять полностью
принятыми по этим локальным тестам.
