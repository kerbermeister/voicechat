# Нативное перетаскивание вложений — 26 октября 2026

Уточнение владельца: desktop drag and drop обязателен не только для web,
но и для macOS и будущих клиентов, включая Windows.

macOS использует NSDraggingDestination окна и стандартный file-URL pasteboard.
Файлы передаются через общий `voicechat/file-drop` в `FileDrop`, затем через
`prepareDroppedFiles` в существующий черновик. Новый пакет не добавлен.
Системный доступ к выбранным файлам удерживается существующим PlatformFiles:
непрозрачные ID, только обычные файлы, порционное чтение и явное release.
Папки/текст/URL и promised files в текущий контракт не входят.

Контракт для будущего Windows-адаптера:
- Dart → native `target`: null запрещает drop; иначе x/y/width/height в логических
  координатах Flutter view, origin слева сверху. Обновлять на layout/resize.
- Native → Dart `hover`: bool для обратной связи.
- Native → Dart `drop`: x/y и files с uri/name/mime/size, как у voicechat/files.
  Ответ true означает передачу владения выбранными файлами чату. false/ошибка/
  отсутствующий обработчик требуют release всех native selections.
- Файлы читать через существующий voicechat/files; не давать произвольный доступ
  к путям. Native-платформа должна реализовать реальный ОС drop и пройти
  физическую приёмку; общий Dart-код сам по себе не является Windows-поддержкой.

Проверки: два widget-теста границ, блокировок, modal и MIME прошли; Flutter analyze
без замечаний. Нативная release-сборка прошла. Пользователь подтвердил реальный
Finder → macOS: фото и файл появились в черновике. Первая попытка не работала:
исправлено явное соответствие NSDraggingDestination; добавлен XCTest на ObjC
селекторы и допустимую геометрию. Все три XCTest прошли на arm64 (Release).
