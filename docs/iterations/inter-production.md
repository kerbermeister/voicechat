# Inter и мягкий контраст — публикация 25 октября 2026

По указанию пользователя изменения влиты в `main` и опубликованы на https://univc.duckdns.org/ из коммита `3bfebcb143a26fa23dd513abeb5a6b3faaf27221`.

Inter подключён локальным variable font asset в общей Flutter-теме веба и Android. В Halo сохранён мягкий контраст (#E0E6F2 / #AFBED8), увеличенные подписи авторов и синий градиент своих сообщений. Снижена жирность заголовков и авторов, сохранено выделение непрочитанных чатов.

Первый CI остановился до деплоя на двух проверках: геометрический тест входа загружал прежний Roboto; форма восстановления с настоящими метриками Inter немного не помещалась на 320×568; шкала аудио наследовала смягчённый цвет текста. Тесты переведены на настоящий Inter, отступы форм адаптированы без уменьшения кнопок, шкала аудио сохранена светлой. Требования тестов не ослаблялись. Локально весь клиентский набор прошёл: 195 тестов, 3 опциональных снимка пропущены; анализатор без замечаний.

Control digest, ID/StartedAt/RestartCount backend-служб, постоянные тома, настройка демонстрации экрана и схема сохранены. Все службы исправны.
