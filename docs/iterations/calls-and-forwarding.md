## Реализация

- MC-09: список чатов понимает служебные `m.call.*`, включая hangup/reject/answer,
  и использует общую подпись для карточек звонков. Завершение без `body` больше
  не отдаётся стандартному форматтеру Matrix с `Unknown message format`.
- MC-10: правая кнопка открывает то же меню, что три точки, в том числе поверх
  выделяемого текста. Пересылка выбирает доступный зашифрованный чат с правом
  отправки; текущий чат включён. Используется существующая durable outbox.
  Переносится содержимое сообщения и имя исходного автора. Ссылки на исходную
  переписку, reply fallback/HTML и сигнализация звонка не копируются. Повторная
  пересылка сохраняет автора. Вложения сохраняют зашифрованные media descriptors;
  истёкшие сообщения отклоняются. Временная копия сохраняет TTL оригинала;
  её срок отсчитывается от отправки копии, как у нового сообщения.
- MC-03: браузерный capture сохраняет facingMode независимо от user agent;
  задняя камера выбирается строго, фронтальная допускает desktop-камеры без
  facingMode. Старый capture освобождается; ошибка восстанавливает предыдущее
  направление. Замена sender ожидает настоящий JS Promise, который теряет
  обёртка dart_webrtc 1.8.2. Обновление mute metadata не запускает повторный
  захват камеры/микрофона в Matrix. Остановка capture выполняется и при закрытом
  peer connection. Это исправление прямого звонка; групповой путь LiveKit сохранён.
- MC-05: активное видео без screen sharing открывается на всё окно; основная
  область отдана собеседнику. Локальное превью разворачивается нажатием,
  скрывается отдельно от передачи видео; доступна также явная кнопка разворота. Есть переключение на плитку, размеры
  плиток учитывают доступную высоту и число участников. Прокрутка остаётся в
  сетке, когда минимальная высота плиток уже не помещается. Камера, микрофон,
  качество и завершение звонка сохранены. Screen sharing сохраняет отдельный путь.
- MC-02: указатель запускает запись сразу при нажатии, отпускание завершает и
  отправляет, сдвиг влево отменяет. Обновление политики не задерживает начало
  записи; при отправке действуют обычные проверки вложений. Для web вместо диалога используется круглый
  live preview с прогрессом, лимитом и кнопкой смены камеры. Canvas сохраняет
  одну видеодорожку MediaRecorder при смене физической камеры; аудиодорожка
  не заменяется. При прерывании результат сохраняется черновиком. Клавиатура и
  assistive activation сохраняют явную кнопку отправки; Escape отменяет web-запись.

## Проверки

Закреплённый Flutter 3.47.7; зависимости не обновлялись.

- Анализатор Dart/Flutter: без замечаний.
- Полный `flutter test --no-pub`: 256 прошли, 3 пропущены.
- Chrome с `--use-fake-device-for-media-stream --use-fake-ui-for-media-stream`:
  три browser-теста прошли. Проверены await/rejection замены sender, запись,
  восстановление после недоступной задней камеры, отпускание, отмена и
  воспроизведение 480×480 с непустыми декодированными пикселями.
- Widget-проверка: начало записи до тайм-аута long press и отмена без отправки;
  совпадение меню, восемь комбинаций пересылки из личного/группового чата в
  личный/групповой, в том числе в текущий чат; сохранение автора.
- Раскладка и controls проверяются на узком и повёрнутом экране; отдельный тест
  проверяет разворачивание превью и плитку. Это не проверка реального видеозвонка.

Команда browser-теста: `CHROME_EXECUTABLE=<Chrome wrapper with fake media flags>
flutter test --no-pub --platform chrome test/video_note_browser_test.dart`.
Обёртка нужна только тесту: физическая камера не запрашивается.

## Открытая приёмка и выпуск

Звонок между двумя физическими iPhone, фактическое переключение тыловой камеры
в Safari/PWA, кружок с реальной камерой и аппаратная регрессия Android не проверены.

Браузерный fake capture не доказывает работу iPhone и не доказывает E2EE медиапотока.

Перед выбором артефактов прочитан production commit из `/srv/voicechat/current.json`:
`5b86730af3d89ea1740f7883207b0ae19e41039a`. Diff всей ветки относительно него включает
предшествующие macOS/Compose/deploy изменения, поэтому eventual release требует

обновлялся. Web-код компилировался и выполнялся browser-тестами; это не release build.
