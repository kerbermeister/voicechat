Исправление сохраняет ожидаемое приглашение до завершения подготовки. Отмена
проверяется по room/session/initiator и использует существующую отмену поколения;
она освобождает public Future, закрывает только соответствующий pending CallProbe
и не рассылает общий group end/leave. Истечение45с, потеря членства и подтверждённый
ответ своего другого устройства также прекращают подготовку. Устаревший UI action
проверяет текущее приглашение, членство, срок и answered-device до push/медиа.
Приглашение также передаёт существующий `join_existing`: после ухода последнего
участника сервер отказывает вместо создания старого разговора. Раньше этот режим
применялся только к discovery. Серверный тест last-departure/join PASS; сервер не менялся.
Нормальный join, действующий разговор другой сессии, криптография, свежая
авторизация и серверная room rotation сохраняются.
