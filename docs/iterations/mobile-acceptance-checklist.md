# Пользовательская приёмка перенесена в единый реестр

С 27 октября 2026 единственный актуальный файл для всего проекта —
[docs/user-acceptance.md](../user-acceptance.md).

В нём объединены непроверенные функции, условия/устройства, известные дефекты,
ожидающие реализации CC-24–34 и уже принятые результаты. Повторяющиеся сценарии
разных итераций объединены под стабильными `UA-xx`.

Подтверждения пользователя по кратким пунктам 12 и 15–20 сохранены.
Сопоставление старых подробных номеров 1–49 и кратких 1–23 находится в разделе
«Связь со старыми номерами» нового реестра. Эта страница оставлена для прежних
ссылок и не содержит отдельной очереди на повторную проверку.
