  вместо технического названия комнаты. Демонстрация — отдельная кнопка.
- Другие собственные устройства получают защищённый сигнал принятия звонка,
  прекращают вызов и показывают имя собеседника или группы.
- Обработка группового приглашения после поздней расшифровки; повторное старое
  приглашение после окончания не возобновляет вызов. Звук завершения однократный.

- Долгое нажатие сообщения открывает меню с иконками. После подтверждённой
  пересылки открывается целевой чат, черновик исходного чата сохраняется.
- Поддержка захвата экрана определяется по API браузера, а не мобильному UA;
  снято такое же ограничение SDK. Работоспособность на iPhone ещё требует
  реального выбора экрана и проверки изображения на другом устройстве.
- В web убрана предварительная пробная запись для проверки доступа к микрофону.
  Постоянное сохранение разрешений после закрытия PWA контролирует iOS/WebKit;
  приложение не обещает обход системных повторных запросов.
