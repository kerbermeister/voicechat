# Состояние реализации и приёмки

Требования: [v0.3](requirements.md). Архитектура задаёт целевую систему; наличие документа не означает наличие кода. Для текущей итерации владелец подтвердил локальный стенд, без реальных SMTP и Firebase.

## Реализовано в локальном клиенте

| Область | Готовый функционал | Граница проверки |
| --- | --- | --- |
| Аккаунт | username, пароль, регистрация с обязательным подтверждением почты, отображаемое имя, восстановление пароля | Synapse + Mailpit; реальной доставки почты нет |
| Собеседники | поиск по username/Matrix ID, открытие существующего или нового личного чата | Локальный каталог Synapse |
| Группы | приватная именованная комната, приглашение/вступление, участники, переименование, исключение по правам, выход | Права исполняет сервер Matrix |
| Переписка | текст, эмодзи, ответы, правки, удаление, реакции | Android ↔ web, E2EE и Matrix relations |
| Медиа | изображения, запись/отправка/воспроизведение голосового | Передача ciphertext, восстановление файлов, запись/воспроизведение на обеих платформах |
| Синхронизация | typing, receipts, непрочитанные, зашифрованная устойчивая очередь, повторы с одним transaction ID | Перезапуск очереди при недоступном транспорте; без дубликата |
| История | локальный поиск текущего текста с учётом правок, догрузка, recovery key и backup, несколько устройств | Полнота поиска явно ограничена загруженной историей |
| Доверие и хранение | Android SQLCipher/Keystore, web vault, ручная сверка Ed25519, отзыв Matrix-устройства | Итерации 1–2 и регрессионные сценарии |
| Звонки | личный WebRTC/TURN, группа LiveKit E2EE, входящий foreground-вызов, принять/отклонить/завершить, mute, участники | Локальный эмулятор/Chrome; до 10 соединений настроено, сквозная приёмка на трёх |
| Интерфейс | адаптивные экраны входа/регистрации, разговоров, чата, участников, проверки устройств/восстановления; Lavender/Ocean/Midnight | Общий Flutter-клиент Android/web |

Детали и команды: [итерация 3](iterations/03-core-messenger.md). Успешный сквозной результат сохраняется в `prototype/verified-core-run.json`; это не сертификат готовности производственного MVP.

## Отложенные работы

- SAS/QR по Matrix и перенос доверия между устройствами. Сейчас ручная независимая сверка Ed25519, без автоматического доверия.
- Подтверждение нового устройства со старого в отдельном пользовательском сценарии и перенос crypto identity; сейчас восстановление проверено через recovery key.
- Удобство vault: подтверждение новой фразы, смена фразы, автоблокировка, безопасная миграция старых профилей.
- Серверный отзыв активных LiveKit-сессий, leases, согласованная смена эпох/ключей. Сейчас клиенты прекращают звонок при изменении прав; это не принудительное отключение на SFU.
- Регистрация по приглашению и администраторская выдача приглашений для реального семейного сервера; локальная регистрация пока ограничена обязательной почтой и loopback-доступом.
- Производственный деплой на VPS: HTTPS/WSS, Docker-образы клиента/control API, секреты, GitHub Actions deploy, подпись release APK, резервное копирование и восстановление.
- Реальные SMTP и FCM, push-шлюз, Android Telecom/foreground service: входящие вызовы при закрытом процессе и заблокированном экране. Локальный сценарий не заменяет эту функцию.
- Публичный TURN/STUN и приёмка прямого ICE без relay, смены Wi-Fi/мобильной сети и длительных обрывов. Локальный личный WebRTC использует принудительный TURN; групповой — LiveKit E2EE.
- Глобальная арбитрация вызовов между несколькими устройствами, позднее присоединение к группе после повторного входа/истечения foreground-приглашения и системный выбор аудиомаршрута.
- Приёмка десяти участников и физических Android, Bluetooth/эхоподавление, Safari/Firefox, доступность и нагрузочные измерения.
- Независимая проверка безопасности до личных переписок. Старые копии у отозванного получателя не стираются.

## Принятые продуктовые правила локальной версии

Редактирование — собственный текст; удаление — собственные сообщения или модератор по правам Matrix, у всех с оговоркой о сохранённых копиях. Новый участник получает историю с момента вступления; новое устройство старого участника восстанавливает доступную историю recovery key. Поиск локальный, по загруженным расшифрованным сообщениям, с явной догрузкой. Вложения до 10 МБ, голосовое до 3 минут; лимиты — настройки первой версии, не SLA.

Отдельно фиксировать, что реализовано, что проверено сквозным сценарием и что требует внешней настройки. Не называть весь MVP готовым до выполнения остающихся обязательных сценариев.
