# Ускорение проверки и развёртывания VoiceChat

Зафиксировано 24 октября 2026 по запросу владельца. Обе задачи выполнены и проверены в изолированном checkout от опубликованного релиза; изменения другого агента не включались. [Результаты, замеры и границы проверки](../iterations/deployment-speed.md).

## DEPLOY-01 — кеш инструментов шифрования и веб-криптомодуля

- [x] Кешировать закреплённые версии Rust/build tools и готовые криптоассеты между запусками GitHub Actions.
- [x] Ключ кеша учитывает ОС/архитектуру runner, версии toolchain/tools, upstream commit криптомодуля, lock-файлы и скрипты генерации. При изменении входных данных пересобирать соответствующий результат.
- [x] При отсутствии кеша полный процесс продолжает работать; секреты и runtime пользователя в кеш не попадают. Существующие проверки сохраняются.
- [x] Измерить холодный и повторный запуски и подтвердить, что минорная правка интерфейса повторно использует криптоассеты, а изменение зависимости вызывает пересборку.

## DEPLOY-02 — отдельный деплой только интерфейса

- [x] Добавить явный режим workflow для обновления только веб-клиента; сохранять immutable digest серверного образа из текущего production release.
- [x] Проверять допустимость режима: изменение backend, Compose, конфигурации, серверных политик или схем БД требует полного деплоя. Не полагаться только на название режима, выбранное человеком.
- [x] Не перезапускать Matrix/PostgreSQL/SFU/TURN при подтверждённом изменении только интерфейса; сохранять выключенную по умолчанию демонстрацию экрана.
- [x] Сохранить учёт current/previous release, защиту от параллельных деплоев, проверку здоровья и откат. Постоянные данные и серверные секреты не изменять; не сокращать резервирование для полных обновлений.
- [x] Проверить успешное обновление, отказ при изменении backend, неуспешную проверку здоровья с откатом и совместимость следующего полного деплоя. Зафиксировать измеренное время.
- [x] Настроить обновление браузерных entrypoint-файлов так, чтобы обычная перезагрузка получала новый клиент без обязательного ⌘⇧R; проверить Chrome со старой вкладкой и сохранёнными локальными данными.

## Наблюдение при проверке регистрации

24 октября 2026: production действительно отдавал релиз `83cda49`, хеш публичного `main.dart.js` совпадал с файлом контейнера. В Chrome владельца сохранялась прежняя ошибка; после ⌘⇧R владелец подтвердил открытие формы. Данные сайта не очищались. У статических файлов на момент проверки отсутствовал явный `Cache-Control`; обновление браузерной версии включено в приёмку DEPLOY-02.
