## Ограничение старой истории

Matrix проверяет history_visibility на момент отправки каждого события.
Смена joined → shared не открывает прежние joined-сообщения задним числом.
Никакие старые события/ключи/серверные state groups не переписываем.
[Правило Matrix](https://spec.matrix.org/v1.1/client-server-api/index.html#room-history-visibility).
Архивы, перенос группы и подмена оригинальных авторов не входят в согласованный объём.
