### Принятые решения

- [x] Повторный дефект по сообщению владельца: отправка задерживалась в очереди. При доступном сервере доставлять E2EE-сообщение на сервер независимо от online получателя; проверить реальные существующие аккаунты и причину ожидания, а не только свежие тестовые профили. Очередь нужна для отсутствия сети/повтора после сбоя, не для ожидания подключения адресата. Не обходить шифрование и не показывать ложную успешную доставку при отсутствии ключей.

  Исправление: `d5e4c8c`, отдельный последовательный worker для каждого чата; сбой одного адресата не удерживает остальные чаты. Существующие демо Bob/Carol получили настоящие E2EE-ключи. Повтор на обновлённой обычной сборке `lib/main.dart`: новое сообщение отключённому Bob подтверждено сервером за 289 мс; ID ответа совпал с ciphertext в истории — PASS. Полная UI-регрессия также PASS. Непройденную проверку/отсутствие ключей не обходить и не объявлять успешной доставкой.
- [x] Присутствие принятого контакта до его вступления в личную комнату: получать реальный online/offline через авторизованный серверный путь; Matrix 403 не выдавать за offline. Ограничить запросы принятыми контактами, проверить последнюю активность и недоступный сервер.

- Первые ключи устройств принимаются по TOFU; замена уже известного ключа блокирует отправку. Это упрощает первый контакт, но первая связь до независимой сверки остаётся уязвимой к подмене сервером. Для независимого подтверждения доступны SAS/QR; результаты приёмки записаны ниже.
- Личный диалог показывает профиль собеседника: изменение имени/аватара комнаты и «Покинуть чат» недоступны. Выход остаётся для групп; удаление истории и блокировка не добавляются без отдельной задачи.
- Вкладки считают непрочитанные чаты, строки — непрочитанные сообщения. У непрочитанной строки более жирное название/превью и круглый badge.
- Уменьшение фото: стороны × 0.5, JPEG 85%; это не гарантия уменьшения байтов ровно вдвое. Параметры задаются сервером.
- Произвольные файлы отправляются отдельными карточками из одной выбранной пачки (до пяти); фотографии — одним альбомом с общей подписью.
- Статусы записи передаются зашифрованными служебными сообщениями Matrix, не сохраняются в историю и истекают через 10 секунд без обновления.
- Согласия контактов хранит только control API. Synapse получает решение через защищённый служебным секретом API; совместное чтение SQLite через Docker исключено из-за устаревшего чтения на локальном стенде.


## Итерация A — фотографии и базовый интерфейс переписки

- [x] Серверный JSON-конфиг: число фото 24, масштаб фото 0.5 по обеим сторонам, JPEG-качество 85, лимит текста; клиент получает настройки и хранит последнюю валидную копию для офлайна. Сжатие происходит **на клиенте до E2EE**, сервер не получает оригинал.
- [x] Множественный выбор фото Android/web, предпросмотр до отправки, удаление выбранного фото; просмотр в полном размере до отправки. Отмена не отправляет изображения.
- [x] Фото и подпись отправляются одним зашифрованным сообщением-альбомом. Плитки со скруглением; полноэкранный просмотр, свайпы/клавиши/стрелки, счётчик и увеличение. Сбой не теряет сохранённую очередь.
- [x] Реальный уровень микрофона во время записи: волна, прошедшее и оставшееся время. После отправки — волна из PCM этой записи, отличимое оформление, прогресс воспроизведения.
- [x] Полный список одновременно печатающих в группе, без замены на одного человека. В списке слева у личного/группового чата — те же имена и плавающие точки; при остановке/тайм-ауте возвращается превью последнего сообщения.
- [x] «Вы печатаете» для собственного пользователя; имена для других, компактный анимированный индикатор.
- [x] Расширенный Unicode emoji picker сеткой с категориями; исходник: https://www.unicode.org/emoji/charts-17.0/ . Без загрузки сторонних картинок/скриптов в переписку.
- [x] Вкладки «Люди»/«Группы» показывают **число непрочитанных чатов**, не сумму сообщений.
- [x] Участники группы: отдельные вкладки «Вступили»/«Приглашены», имена и статусы, различимые строки. Заголовок показывает оба счётчика; приглашённый не выдаётся за вступившего.
- [x] Отдельное окно входящих приглашений пользователя: кто и куда пригласил, принять/отклонить; счётчик у кнопки.
- [x] Разделители сообщений по локальным календарным дням: сегодня, вчера, дата.
- [x] Ненавязчивый счётчик текста; исходный поиск списка явно называется поиском по имени чата, без обещания искать историю.
- [x] Проверки E2EE/повторов альбома, WAV/волны, границ конфигурации и адаптивной компоновки. Web и Android-сборка; физический телефон — отдельная приёмка.

**Согласовано:** 50% означает ширину × 0.5 и высоту × 0.5 с сохранением пропорций. Это не обещание уменьшить размер файла ровно вдвое. Оригиналы не отправляются автоматически. JPEG-преобразование фото удаляет EXIF; прозрачность при JPEG надо обработать явно.

## Итерация D — звонки, реакции и стабильность интерфейса

- [x] Звуки отправки и получения сообщения, исходящего вызова (ожидание ответа) и входящего звонка. Управление звуками в настройках, без дублей после синхронизации/перезагрузки/повтора очереди, без сигналов на старую историю; учитывать mute/аудиофокус Android и browser autoplay/user gesture. Звонок прекращает звуковой цикл при ответе, отмене, отклонении и тайм-ауте.

- [x] Личный исходящий звонок: отдельное окно с именем/аватаром, анимацией вызова, микрофоном и отменой. Офлайн собеседника не отменяет попытку автоматически: показываем ожидание/тайм-аут и понятный итог. Отдельно проверить причину нынешнего моргания/исчезновения при запуске.
- [x] Групповой звонок: модальное окно или отдельный экран с явными состояниями «ждём», «подключается», «в звонке», «восстанавливаем связь», mute и завершением; виден каждый приглашённый/подключённый.
- [x] Одна активная реакция каждого пользователя на сообщение. Новый эмодзи заменяет предыдущий; повторное нажатие снимает реакцию. Обработать старые несколько реакций и гонку нескольких устройств без удаления реакций других пользователей.
- [x] Проверить мерцание при реакциях и действиях: стабильные ключи/состояние виджетов, отсутствие повторной загрузки вложений и всей переписки, сохранение фокуса/прокрутки. Изменяется только нужный элемент, плавные локальные анимации, без пересборки визуальной структуры и скачков высоты. Десктоп и Android-эмулятор, включая reduced motion; физический телефон остаётся общей отдельной приёмкой.

## Поиск: принятое направление

Сейчас поле слева фильтрует имена существующих комнат, а поле внутри чата — загруженные сообщения. Эти области нужно явно различать. В дальнейшем общий поиск объединит разделы «Чаты» и «Сообщения»; календарь относится к истории. Ориентир — разделение чатов, сообщений, медиа и дат в привычных мессенджерах: https://core.telegram.org/api/search и https://telegram.org/blog/filters-anonymous-admins-comments . Копировать серверный поиск незашифрованной истории для нашей E2EE-модели нельзя.

### Уточнение счётчиков

Счётчик уведомлений Matrix обнуляется при mute и не равен числу непрочитанных сообщений. Для выбранного Synapse включаем `org.matrix.msc2654.unread_count` и сохраняем его отдельно в зашифрованной базе, с обычным счётчиком как fallback старых данных. Настройка mute по-прежнему использует стандартные push rules. Источник: установленная реализация Synapse (`synapse.rest.client.sync`) и предложение https://github.com/matrix-org/matrix-spec-proposals/pull/2654 . Не выдаём экспериментальное поле за универсальную поддержку любого homeserver.

### Решение по первому сообщению офлайн

Личный чат имеет `history_visibility=invited`: принятый контакт может получить ключ на уже зарегистрированное устройство и прочитать сообщения с момента приглашения, даже если ещё не открыл комнату. Перед отправкой заново проверяются токен, актуальное членство, согласие контакта и ключи устройств. Если ключа получателя ещё нет (аккаунт ни разу не активировал E2EE), сообщение остаётся в защищённой очереди, а не отправляется только самому себе. Группы сохраняют `joined`: приглашённым участникам новые ключи до вступления не передаются.

### Локальное доверие не является серверными account data

Пространство `dev.voicechat.local.*` зарезервировано для зашифрованного локального хранилища и отфильтровывается на входе Matrix sync. Серверное событие с таким именем не может заменить закреплённые ключи, согласия контактов, очередь отправки или границу истории. Регрессионный тест сначала воспроизвёл перезапись, после исправления проверяет сохранность локальных значений и обычную обработку разрешённых account data.
