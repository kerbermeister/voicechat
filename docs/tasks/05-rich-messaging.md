21 октября 2026. Выполняется итерациями; наличие задачи не означает готовность функции. Прежние SAS/QR и серверный отзыв звонков остаются отдельными отложенными работами.

### Принятые решения

- Первые ключи устройств принимаются по TOFU; замена уже известного ключа блокирует отправку. Это упрощает первый контакт, но первая связь до независимой сверки остаётся уязвимой к подмене сервером. SAS/QR остаётся отдельной ранее отложенной задачей.
- Личный диалог показывает профиль собеседника: изменение имени/аватара комнаты и «Покинуть чат» недоступны. Выход остаётся для групп; удаление истории и блокировка не добавляются без отдельной задачи.
- Вкладки считают непрочитанные чаты, строки — непрочитанные сообщения. У непрочитанной строки более жирное название/превью и круглый badge.
- Уменьшение фото: стороны × 0.5, JPEG 85%; это не гарантия уменьшения байтов ровно вдвое. Параметры задаются сервером.
- Произвольные файлы отправляются отдельными карточками из одной выбранной пачки (до пяти); фотографии — одним альбомом с общей подписью.
- Статусы записи передаются зашифрованными служебными сообщениями Matrix, не сохраняются в историю и истекают через 10 секунд без обновления.
- Согласия контактов хранит только control API. Synapse получает решение через защищённый служебным секретом API; совместное чтение SQLite через Docker исключено из-за устаревшего чтения на локальном стенде.


## Итерация A — фотографии и базовый интерфейс переписки

- [x] Серверный JSON-конфиг: число фото 24, масштаб фото 0.5 по обеим сторонам, JPEG-качество 85, лимит текста; клиент получает настройки и хранит последнюю валидную копию для офлайна. Сжатие происходит **на клиенте до E2EE**, сервер не получает оригинал.
- [ ] Множественный выбор фото Android/web, предпросмотр до отправки, удаление выбранного фото; просмотр в полном размере до отправки. Отмена не отправляет изображения.
- [ ] Фото и подпись отправляются одним зашифрованным сообщением-альбомом. Плитки со скруглением; полноэкранный просмотр, свайпы/клавиши/стрелки, счётчик и увеличение. Сбой не теряет сохранённую очередь.
- [ ] Реальный уровень микрофона во время записи: волна, прошедшее и оставшееся время. После отправки — волна из PCM этой записи, отличимое оформление, прогресс воспроизведения.
- [ ] Полный список одновременно печатающих в группе, без замены на одного человека. В списке слева у личного/группового чата — те же имена и плавающие точки; при остановке/тайм-ауте возвращается превью последнего сообщения.
- [x] «Вы печатаете» для собственного пользователя; имена для других, компактный анимированный индикатор.
- [x] Расширенный Unicode emoji picker сеткой с категориями; исходник: https://www.unicode.org/emoji/charts-17.0/ . Без загрузки сторонних картинок/скриптов в переписку.
- [ ] Вкладки «Люди»/«Группы» показывают **число непрочитанных чатов**, не сумму сообщений.
- [ ] Участники группы: отдельные вкладки «Вступили»/«Приглашены», имена и статусы, различимые строки. Заголовок показывает оба счётчика; приглашённый не выдаётся за вступившего.
- [ ] Отдельное окно входящих приглашений пользователя: кто и куда пригласил, принять/отклонить; счётчик у кнопки.
- [x] Разделители сообщений по локальным календарным дням: сегодня, вчера, дата.
- [ ] Ненавязчивый счётчик текста; исходный поиск списка явно называется поиском по имени чата, без обещания искать историю.
- [ ] Проверки E2EE/повторов альбома, WAV/волны, границ конфигурации и адаптивной компоновки. Web и Android-сборка; физический телефон — отдельная приёмка.

**Согласовано:** 50% означает ширину × 0.5 и высоту × 0.5 с сохранением пропорций. Это не обещание уменьшить размер файла ровно вдвое. Оригиналы не отправляются автоматически. JPEG-преобразование фото удаляет EXIF; прозрачность при JPEG надо обработать явно.

## Итерация B — видео и произвольные файлы

- [ ] Выбор видео и файлов любого типа, отдельные узнаваемые карточки и явная загрузка. По умолчанию лимиты видео/файла — по 300 МиБ, отдельно регулируются сервером и согласованы с Synapse/reverse proxy.
- [ ] Большие вложения: прогресс, отмена/повтор, отсутствие гигантского base64-снимка всей очереди, контроль памяти Android/web; E2EE и защищённый локальный кэш. Принимать файл размером 300 МиБ нельзя объявлять готовым после маленького mock-файла.
- [ ] Видеокружок: камера только после действия пользователя, круглый предпросмотр, прогресс по часовой стрелке, максимум 60 секунд из серверной настройки, отмена/отправка.
- [ ] Android: фронтальная/основная камера, поворот/соотношение сторон, разрешения, прерывание приложением/звонком, звук и очистка временных данных.
- [ ] Круглый плеер в истории, воспроизведение/пауза/прогресс, восстановление истории и медиа на другом устройстве.

## Итерация C — аватары, события звонков и поиск

- [ ] Дополнительные темы из выбранных морских референсов: «Лагуна», «Коралловый риф», «Биолюминесценция», «Закат в бухте». Lavender Soft остаётся основной. Сохранение выбора и проверка читаемости всех новых медиа/окон в светлых и тёмных темах.

- [ ] Авторство реакций: tooltip при наведении на реакцию на десктопе, список пользователей по нажатию/долгому нажатию на телефоне. Показывать актуальные реакции без удалённых, учитывать несколько эмодзи одного пользователя.

- [ ] Аватар пользователя и группы: выбрать фото, масштабировать/центрировать кадр, сохранить, показывать выбранную область в скруглённой форме. Проверка прав на изменение группы. Объяснить, что Matrix-аватары являются метаданными профиля/комнаты и не имеют той же E2EE-защиты, что вложения чата.
- [ ] События начала/завершения звонка отдельными карточками с иконками/цветом. Длительность из реального состояния вызова; не включать ожидание ответа и не выдумывать длительность для старых событий без данных. Личные и групповые сценарии учитывать отдельно.
- [ ] Общий поиск: чаты по имени + фраза по доступной **локально расшифрованной** истории с указанием охвата и переходом к сообщению. Нельзя обещать серверный полнотекстовый поиск по E2EE ciphertext.
- [ ] Календарь в истории: выбор дня, догрузка/переход к сообщениям за этот день, явные «сообщений нет»/«история ещё не загружена». Временная зона пользователя, границы суток и смена года.
- [ ] Мобильная приёмка всех новых окон, сеток, клавиатуры, жестов, safe area, жизненного цикла и больших файлов. Не приравнивать браузер шириной 390 px к физическому Android.

## Итерация D — звонки, реакции и стабильность интерфейса

- [ ] Звуки отправки и получения сообщения, исходящего вызова (ожидание ответа) и входящего звонка. Управление звуками в настройках, без дублей после синхронизации/перезагрузки/повтора очереди, без сигналов на старую историю; учитывать mute/аудиофокус Android и browser autoplay/user gesture. Звонок прекращает звуковой цикл при ответе, отмене, отклонении и тайм-ауте.

- [ ] Личный исходящий звонок: отдельное окно с именем/аватаром, анимацией вызова, микрофоном и отменой. Офлайн собеседника не отменяет попытку автоматически: показываем ожидание/тайм-аут и понятный итог. Отдельно проверить причину нынешнего моргания/исчезновения при запуске.
- [ ] Групповой звонок: модальное окно или отдельный экран с явными состояниями «ждём», «подключается», «в звонке», «восстанавливаем связь», mute и завершением; виден каждый приглашённый/подключённый.
- [ ] Одна активная реакция каждого пользователя на сообщение. Новый эмодзи заменяет предыдущий; повторное нажатие снимает реакцию. Обработать старые несколько реакций и гонку нескольких устройств без удаления реакций других пользователей.
- [ ] Проверить мерцание при реакциях и действиях: стабильные ключи/состояние виджетов, отсутствие повторной загрузки вложений и всей переписки, сохранение фокуса/прокрутки. Изменяется только нужный элемент, плавные локальные анимации, без пересборки визуальной структуры и скачков высоты. Проверка десктоп/телефон и reduced motion.

## Поиск: принятое направление

Сейчас поле слева фильтрует имена существующих комнат, а поле внутри чата — загруженные сообщения. Эти области нужно явно различать. В дальнейшем общий поиск объединит разделы «Чаты» и «Сообщения»; календарь относится к истории. Ориентир — разделение чатов, сообщений, медиа и дат в привычных мессенджерах: https://core.telegram.org/api/search и https://telegram.org/blog/filters-anonymous-admins-comments . Копировать серверный поиск незашифрованной истории для нашей E2EE-модели нельзя.

## Дополнение E — контакты, профиль и уточнения интерфейса

- [ ] При выключенной настройке: запрос, входящий/исходящий статус ожидания, принять/отклонить, отправитель видит отказ; добавление в «Люди» после принятия.
- [ ] Приглашения: отдельные вкладки «Люди»/«Группы», входящие/исходящие и их актуальные состояния. Группа всегда с подтверждением; приглашать можно только добавленные контакты.
- [x] TOFU по выбору владельца: первые ключи принимаются автоматически без UX-подтверждения; смена известных ключей блокируется. Задокументировать риск первой связи и не сбрасывать сохранённое доверие при изменении списка устройств.
- [ ] Карточка профиля: ник, username, аватар, presence/последний онлайн, написать/запросить контакт; открытие из участников группы и по собственной аватарке.

- [ ] Presence: достоверные online/offline/unavailable, зелёный/нейтральный индикатор, последнее время онлайн только вне online; неизвестные данные не выдавать за онлайн. Проверить серверную публикацию presence и обновление клиента.

- [ ] Усилить визуальную чувствительность реального микрофонного wave без декоративного/случайного сигнала.
- [ ] Мобильный видеокружок рядом с микрофоном: удержание записывает, отпускание отправляет; отмена, лимит и обработка ошибок.

- [x] История после повторного открытия чата: сохранить уже раскрытый диапазон, не возвращать окно к стандартным последним сообщениям; не показывать «загрузить» после достижения начала истории. Проверить фактическую сохранность событий в зашифрованной базе и корректность текста о полноте поиска.

- [ ] Статусы активности: различать «печатает», «записывает голосовое» и «записывает видеокружок» в переписке и превью слева. В группе показывать каждого активного участника и его действие, для себя — «Вы …». Сброс при остановке/отмене/отправке, отключении и истечении TTL; совместимость с обычным Matrix typing без передачи содержимого сообщения.

- [x] Личный диалог: убрать «Покинуть чат»; оставить выход только для групп. Не добавлять удаление контакта или истории под видом выхода.

- [ ] Непрочитанное в каждой строке людей/групп: круглый badge с числом непрочитанных сообщений, выделенное начертание названия/превью, читаемый акцент во всех темах. Обновлять после входящих и прочтения; счётчик вкладки по-прежнему считает чаты, а не сообщения. Проверить несколько чатов и другое устройство.

## Следующая итерация F — видеозвонки и качество связи

Начинать после выполнения и приёмки предыдущих пунктов; разрешение на самостоятельный выбор реализации получено. Работа с камерой/видео не отменяет E2EE, отзыв доступа и ограничения доверия ключам.

- [ ] Личные видеозвонки и групповые видеоконференции до 10 участников; понятные кнопки камеры/микрофона, выбор/переключение камеры, состояния приглашения/ожидания/подключения.
- [ ] Выбор качества: «Авто», низкое, среднее, высокое. Конкретные ограничения разрешения/FPS/битрейта задокументировать по возможностям SDK; не обещать выбранное разрешение при недостаточной сети.
- [ ] «Авто»: использовать адаптивный битрейт/слои SDK и актуальную статистику соединения; быстро снижать нагрузку при потерях и осторожно повышать после восстановления. Согласовать подписки и размеры плиток, не декодировать лишние максимальные потоки.
- [ ] Индикатор качества соединения постоянно во время аудио- и видеозвонков: измеренное качество, понятные состояния/объяснение; недоступную статистику не подменять выдуманными полосками.
- [ ] Отдельные карточки начала/завершения видеозвонка; длительность только реального соединения, без времени дозвона. Совместимость старых аудиособытий.
- [ ] Восстановление после потери сети, смены Wi-Fi/мобильной сети, фона/возврата приложения; сохранение выбранного качества и корректная остановка камеры при отмене/завершении/ошибке.
- [ ] Контроль E2EE каждого медиапотока, прав publish/subscribe и отзыва устройств: разрешать камеру только в видеосценарии, не расширять существующий аудиогрант без проверки.

### Уточнение счётчиков

Счётчик уведомлений Matrix обнуляется при mute и не равен числу непрочитанных сообщений. Для выбранного Synapse включаем `org.matrix.msc2654.unread_count` и сохраняем его отдельно в зашифрованной базе, с обычным счётчиком как fallback старых данных. Настройка mute по-прежнему использует стандартные push rules. Источник: установленная реализация Synapse (`synapse.rest.client.sync`) и предложение https://github.com/matrix-org/matrix-spec-proposals/pull/2654 . Не выдаём экспериментальное поле за универсальную поддержку любого homeserver.

### Решение по первому сообщению офлайн

Личный чат имеет `history_visibility=invited`: принятый контакт может получить ключ на уже зарегистрированное устройство и прочитать сообщения с момента приглашения, даже если ещё не открыл комнату. Перед отправкой заново проверяются токен, актуальное членство, согласие контакта и ключи устройств. Если ключа получателя ещё нет (аккаунт ни разу не активировал E2EE), сообщение остаётся в защищённой очереди, а не отправляется только самому себе. Группы сохраняют `joined`: приглашённым участникам новые ключи до вступления не передаются.

### Локальное доверие не является серверными account data

Пространство `dev.voicechat.local.*` зарезервировано для зашифрованного локального хранилища и отфильтровывается на входе Matrix sync. Серверное событие с таким именем не может заменить закреплённые ключи, согласия контактов, очередь отправки или границу истории. Регрессионный тест сначала воспроизвёл перезапись, после исправления проверяет сохранность локальных значений и обычную обработку разрешённых account data.

### Повторная приёмка E

- Flutter: 42 теста прошли, включая запрет подмены локальных account data, доверие первым ключам, отказ при смене ключа, офлайн-получателя без согласия/ключей, раздельные счётчики сообщений и уведомлений, полный список десяти печатающих и контраст семи тем.
- Android-эмулятор: запись видеокружка, переключение камеры до записи, лимит и прерывание через общий координатор с сохранением в черновик — PASS (`integration_test/media_capture_test.dart`). Физическая камера и аудиомаршруты не проверены.
- Индикация активности в истории накладывается поверх нижней части списка: полный текст не обрезается и не перестраивает сообщения; при малой доступной высоте его можно прокрутить. Боковая строка остаётся одной высоты, полный текст доступен в подсказке.
- Обновлённый прогон клавиатуры/мобильных окон, первого сообщения офлайн и полный медиапрогон пока не завершены; соответствующие пункты не отмечены готовыми.
