# Nocturne: полный мобильный артбук

Открыть `index.html` в браузере. HTML самодостаточен; сервер и сеть для просмотра не нужны. Локальное превью: http://127.0.0.1:8766/nocturne-mobile-complete/.

115 авторских экранов и ключевых состояний по текущему Flutter-клиенту: 114 для Android и 113 для мобильного веба. Это предложения дизайна, не снимки работающего приложения. Список функций и источников — в `inventory.json` и раскрываемой матрице в конце артбука.

Размеры в логических CSS-пикселях: 390×844, 360×800, 320×568. Системные области входят в эту высоту; web-панели занимают дополнительные 88 px внутри неё. Клавиатура — схематичная модель 240 px, на компактном экране 200 px. Содержимое длинных экранов прокручивается внутри. Реальные панели браузеров, безопасные зоны и клавиатуры различаются.

В каталоге доступны платформа, размер телефона, раздел, конкретный экран, поиск функций и масштаб текста 100/125%. Подписанные кнопки открывают соответствующий референс либо уведомление о демонстрационном действии; отправки данных и захвата камеры нет.

## Файлы

- `build.py` — генератор на стандартной библиотеке Python. Использует словарь SVG-иконок из соседнего `../artbook-2026-10/build.py` через AST, не исполняя его.
- `index.html` — артбук.
- `inventory.json` — экраны, функции, компоновка и исходные файлы клиента.
- `previews/` — снимки каждого применимого экрана в Chrome при 390×844; длинные области показаны в исходной позиции, чат — у последних сообщений.
- `overview.png`, `group-*.jpg` — обзор и контактные листы.
- `verification.json` — проверки геометрии всех применимых экранов: 2 платформы × 3 размера × 2 масштаба текста.
- `interaction-check.json` — проверка перехода, поиска, клавиатуры и ширины каталога при 320 px.

Пересборка: `python3 docs/design/nocturne-mobile-complete/build.py` из корня проекта. После изменения генератора снимки и отчёты нужно обновить отдельно.

Проверки HTML не заменяют тестирование Flutter на устройстве: клавиатура, TalkBack, системные разрешения и медиасценарии требуют проверки при внедрении. Код приложения этим артбуком не изменяется.
