# VoiceChat · артбук 10 × 6

[Открыть артбук](index.html). Локальный HTML, без сети и внешних зависимостей. Выбор направления, сравнение одного экрана во всех стилях, печать. Каждый экран связан с исходным снимком текущего клиента.

10 направлений: Paperline, Tide, Moss, Signal, Nocturne, Atelier, Prism, Grid / Studio, Orbit, Quiet. В каждом — разговоры, переписка, группа, звонок, настройки, устройства. Всего 60 макетов. Развитие предыдущего артбука `../artbook-2026-10`; исходная редакция сохранена.

Карта функций в конце артбука фиксирует маршруты для дополнительных диалогов, входа, вложений, расписания, восстановления истории и экспериментальной демонстрации экрана. Это статические визуальные предложения с демонстрационными данными. Рабочий Flutter-клиент не изменён; функционал не переимплементирован в HTML.

Сборка из корня репозитория:

```sh
python3 docs/design/artbook-six-screens/build.py
```

Проверка требует уже доступных Playwright для Node и Google Chrome на macOS (при необходимости задать NODE_PATH на имеющийся runtime):

```sh
node docs/design/artbook-six-screens/verify.cjs
```

Проверяются количество направлений и макетов, отсутствие переполнения на ширинах 320, 375, 768 и 1440, локальные ссылки, фильтр, переход к направлению и ошибки JavaScript. Результат — `verification.json`; по каждому направлению сохраняется PNG.

Использован ui-ux-pro-max: design-system для messaging, стили, рекомендации Flutter по масштабированию текста. Landing-page часть рекомендации не применена. Композиции, материалы и типографика разработаны с учётом текущих экранов приложения.

Не проверены реальные устройства, Flutter-реализация, вся матрица состояний, скринридеры и медиасоединение. Уменьшенные артбук-макеты не являются спецификацией размеров касаний. Основной риск переноса — сохранение доступности и читаемости при увеличении шрифта и открытой клавиатуре; это требует проверки выбранного варианта в приложении.
