# Обязательные доработки дизайна

Основа: текущий вариант «после» Lavender Soft. Общие Flutter-компоненты для Android и веба, адаптивная компоновка для мобильного и большого экрана.

- [x] Входящий и текущий звонок: крупный аватар, имя по центру, явный статус, заметный таймер, анимация входящего вызова, пять делений реального качества связи.
- [x] Голосовые сообщения: более заметная карточка и выразительная диаграмма фактической звуковой волны.
- [x] Проверка личности: отдельные блоки аккаунта, устройства и отпечатка; копирование устройства и отпечатка нажатием.
- [x] Устройства аккаунта: визуально отделённые карточки устройств.
- [x] Локальное хранилище: круговая диаграмма занятого и оставшегося объёма в пределах лимита локальной копии, без подмены свободного места на диске.
- [x] Более компактные сообщения и список людей/групп с сохранением доступности и читаемости.
- [x] Информация о группе: нижняя панель кнопок с иконками и подписями «Аватар», «Пригласить», «Название», «Покинуть», «Закрыть».
- [x] Русский календарь дат переписки и планирования сообщений.
- [x] Свежие снимки всех 35 экранов на Android и мобильном вебе, обновлённая галерея и запущенная полноценная веб-версия.
- [x] Проверки общего кода, мобильной и широкой компоновки: 123 Flutter-теста прошли.

Публикация на основном сайте — отдельный этап после проверки сборки. Изменения в общем коде применяются при следующей сборке сайта и Android-приложения.

## Реализация

- Звонок: общий `CallWindow`, таймер из фактической длительности, пять делений из `CallQuality`; неизвестное качество не заполняет деления. Пульсация входящего звонка отключается системной настройкой уменьшения анимаций.
- Идентификаторы: общий `IdentityField` копирует точное значение и сообщает результат. Нажатие не меняет доверие к устройству.
- Хранилище: кольцо показывает долю от лимита локальной копии, а не свободное место всего устройства. Превышение лимита отображается отдельно; оставшийся объём не бывает отрицательным.
- Компактность: меню сообщения расположено рядом с содержимым; собственное сообщение не дублирует подпись «Вы». Размер шрифта 15, уменьшены интервалы. В списке чатов уменьшены аватар, отступы и разделители.
- Группа: общая нижняя панель сохраняет исходные проверки прав и подтверждение выхода.
- Календарь: стандартные локализации Flutter с русской локалью во всём приложении, включая планирование.

## Результат проверки

- `flutter analyze`: замечаний нет. Полный набор: 123 теста прошли.
- По 35 экранов Android (эмулятор API 35) и мобильного веба (Chrome 390 × 844); после последней правки подписи дополнительно пересняты оба экрана группы и повторно пройден весь сценарий.
- [Текущее сравнение](index.html): одобренный вариант → итоговые доработки. [Первоначальное сравнение](original.html): интерфейс до первого редизайна → текущая версия.
- Обычные сборки `main.dart` Android и веба созданы без встроенных учётных данных галереи. Открытие веба проверено на 1440 × 1000 и 390 × 844; экран входа Android подтверждён в дереве доступности эмулятора.
- Полноценная локальная веб-версия: http://localhost:7357/. Галерея: http://localhost:7365/. Для просмотра галереи без сервера распакуйте архив и откройте `index.html`.
- Публикация на основной сайт не выполнялась. Реальный телефон, камера, микрофон и медиапотоки звонков не проверялись; изображения звонков используют явно обозначенные тестовые состояния.
