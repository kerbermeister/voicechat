# Предварительные референсы морских тем

Зафиксировано по выбору владельца 21 октября 2026.

**Статус: предварительные кандидаты для дополнительных тем. Основным визуальным референсом проекта остаётся [Lavender Soft](../README.md).** Эти варианты не заменяют его и не означают, что все четыре темы утверждены к реализации. Это направление дальнейшего исследования, а не буквальная спецификация экранов.

| Выбранный вариант | Визуальная идея |
| --- | --- |
| Лагуна | Бирюза и песок, мягкие островки переписок |
| Коралловый риф | Коралловые и зелёные акценты, органические формы |
| Биолюминесценция | Тёмный океан, мягкое свечение и светящиеся звуковые дорожки |
| Закат в бухте | Абрикосовые и лиловые оттенки, горизонт и тёплые переливы |

- [Предпросмотр четырёх выбранных тем](references.html)
- [Редактируемый исходник эскизов](references.fragment.html)

В предпросмотре сохранены только выбранные варианты. Имена, сообщения, состояния звонка и реакции кнопок демонстрационные. Это не реализация приложения. Для загрузки иконок может потребоваться интернет.

## Идея на будущее: анимированные темы

Владелец хотел бы рассмотреть анимации для этих четырёх тем: например, фоновые пузырьки, капельки в воздухе или другие мягкие морские эффекты. Темы могут иметь анимированное оформление.

Сейчас фиксируется только идея: примеры анимаций не создаются, конкретные эффекты и обязательность их реализации не утверждены. При дальнейшем проектировании предусмотреть спокойную статическую версию, возможность отключить движение и учёт системной настройки уменьшения анимации. Эффекты не должны мешать чтению, управлению звонком или создавать лишнюю нагрузку на устройство.
