# Halo: варианты типографики

Локальный HTML-эскиз для выбора гарнитуры. Открыть `index.html` через локальный HTTP-сервер (текущий просмотр: http://localhost:7364/). `comparison.html` и `comparison.png` показывают четыре варианта рядом.

- Onest — рекомендуемое мягкое оформление.
- Golos Text — спокойная альтернатива для длинной русской переписки.
- Manrope — более геометричное оформление.
- Inter — нейтральное оформление интерфейса.

Одна гарнитура во всех ролях каждого варианта. Сообщения 14/400, авторы 14/500 (сохранён увеличенный размер), заголовки 18–22/500. Основной текст #E0E6F2 вместо #F1F3FA; переключатель позволяет сравнить исходный цвет. Цвета своих сообщений взяты из текущего Halo: #365B8B → #304E77. Проверенные пары текста/поверхностей имеют контраст 4.66:1 или выше.

Шрифты и OFL-лицензии из https://github.com/google/fonts/tree/main/ofl сохранены локально в `fonts/`; для просмотра не требуется обращение к Google Fonts. Проверена загрузка всех четырёх TTF, переключение гарнитуры и мобильного режима во встроенном браузере.

Это эскиз на вымышленных данных, а не проверка реальных Flutter-компонентов. Приложение и VPS не изменены. После выбора нужна отдельная интеграция общей типографики и проверка переносов, масштабирования текста и физического Android.

## Выбранный вариант применён

По указанию пользователя Manrope и мягкий контраст подключены в общей Flutter-теме на ветке `codex/halo-manrope-soft`. Локальная release web-сборка обновлена на http://localhost:7362/. Анализатор без замечаний, 25 целевых тестов и opt-in capture прошли; [снимки реальных компонентов](applied.html). Проверены новая JS-сборка, TTF, crypto assets и control health на 8090; ошибок консоли встроенного браузера нет. Предыдущая локальная сборка сохранена для возврата. VPS не обновлялся. Физический Android и медиазвонки в этой итерации не проверены.
