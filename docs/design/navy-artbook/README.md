# VoiceChat · Navy Collection

Открыть `index.html` локально. 10 авторских вариантов, 6 основных экранов в каждом, 10 широких веб-компоновок. Генератор использует общие компоненты и токены для Android/mobile web и desktop web.

Варианты: Haven, Lumen, Studio, Cove, Halo, Frost, Aurora, Ribbon, Pearl, Meridian. Экраны: разговоры, личный чат, группа, видеозвонок, настройки, устройства. Каждый макет связан с исходным экраном текущей реализации. Кнопки показывают маршруты существующих функций в модальном окне; реальные операции с аккаунтом не выполняются.

## Сборка и проверка

```sh
python3 docs/design/navy-artbook/build.py
node docs/design/navy-artbook/verify.cjs
```

Для проверки используются имеющиеся Playwright и Google Chrome. При необходимости задать NODE_PATH и CHROME_PATH на уже установленные инструменты. Скрипт проверяет 60 экранов, 10 веб-компоновок, переполнение, маршруты кнопок, ссылки, изображения, переключения, modal/Escape и базовые контрастные пары. Отчёт — `verification.json`. PNG сохраняются рядом с HTML.

`styles.css` — общий дизайн-код и различия компоновок. `tokens.json` — палитры и радиусы. `book.js` — навигация артбука. `build.py` — экраны и карта маршрутов. Иконки извлекаются из существующего семейства проекта без исполнения старого генератора.

## Основа

ui-ux-pro-max: design-system для messenger / soft / dark blue, Soft UI Evolution и Adobe Spectrum. Общая рекомендация landing page не применена. Принципы проверены по [Spectrum Colors](https://spectrum.adobe.com/page/color-system/) и [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials). Это собственные токены VoiceChat, не официальная реализация систем Adobe/Apple.

Портрет в `assets/call-portrait.png` сгенерирован imagegen: вымышленный человек, не пользовательские данные. Все имена, ID, сообщения, статусы вызова и проверки — демонстрационные.

## Ограничения

Приложение не изменено. Это артбук, не работающий клиент. Все шесть основных экранов отрисованы; дополнительные состояния представлены картой маршрутов и пояснениями. Нет аппаратной проверки Android, медиасоединения или E2EE. Текстовое масштабирование, клавиатура и полный аудит доступности выбранного направления потребуют проверки в Flutter. Базовые контрасты токенов не заменяют аудит всех наложений и состояний.
