# VoiceChat

Личный мессенджер для друзей и семьи: Android APK и адаптивное веб-приложение.

Основной стек согласован: Flutter, Matrix/Synapse, PostgreSQL, WebRTC и LiveKit с E2EE. Проект находится на этапе детализации архитектуры; приложение ещё не реализовано. Развёртывание планируется на одном VPS через Docker Compose и GitHub Actions.

- [Требования v0.3](docs/requirements.md)
- [Выбранные технологии](docs/technology-proposal.md)
- [Детальная архитектура v1](docs/architecture/README.md) — компоненты, данные, шифрование, звонки и эксплуатация.

Открытые вопросы и проверки интеграций отмечены отдельно от принятых решений. Команды запуска и CI/CD будут реализованы на этапе инфраструктуры.

- [Решения: один VPS, развёртывание и восстановление](docs/architecture-decisions.md)
