# VoiceChat prototype

Flutter-клиент для Android и web. Запуск и ограничения: [лаборатория E2EE](../../prototype/README.md).

`lib/main.dart` — ручной прототип с темами Lavender Soft, Ocean Calm и Midnight.
`lib/lab_main.dart` — отдельный автоматический сквозной сценарий на одноразовых аккаунтах.

Android и мобильный web используют общую адаптивную компоновку Lavender Soft. В узком чате поле ввода, голосовое сообщение и отправка всегда на виду; кнопка «+» раскрывает фото, файлы, эмодзи, временные и отложенные сообщения и видеокружки. На широком экране действия остаются в одной строке.

Сравнение экранов: [галерея до / после](../../docs/design/mobile-refresh/index.html). Проверки узких экранов и клавиатуры — `flutter test test/mobile_layout_test.dart`; сценарий снимков — `integration_test/design_gallery_test.dart` (только одноразовый аккаунт `ui_*` из локального fixture, без реального захвата микрофона и камеры).


### Доработки Lavender Soft от 23 октября

Android и сайт используют общий интерфейс из `lib/`: экран звонка с аватаром, пульсацией входящего вызова, таймером и пятью делениями качества; компактные сообщения и список чатов; выделенные голосовые карточки; копирование идентификаторов; карточки устройств; диаграмма локальной копии; нижняя панель группы; русская локализация календарей. Свободный объём в настройках относится к лимиту локальной копии, а не к диску целиком.

Обязательные задачи и проверка: [список](../../docs/design/mobile-refresh/tasks.md). Новые проверки: `flutter test test/design_refinements_test.dart test/call_window_test.dart`. Сборка общего веб-интерфейса: `flutter build web`; публикация на основной сайт требует отдельного развёртывания.

Сборки Android и веба запускайте последовательно: Flutter перегенерирует общий `GeneratedPluginRegistrant.java`, а release web исключает тестовый плагин. Для снимков каждой платформы нужен отдельный новый аккаунт `ui_*`, так как сценарий создаёт собственную группу «Семья».


### Основной сайт и очереди

`python3 prototype/serve_app.py` из корня проекта запускает обычный сайт :7357 вместе с обязательным API :8090. [Итерация 6](../../docs/iterations/06-main-site-and-send-queue.md) описывает исправление временных сообщений и строку «Запланировано · N» под поиском. Она открывает очередь с датами, статусами и расшифрованным на устройстве содержимым; отправленные и отменённые задания в счётчик не входят.

[Итерация 7](../../docs/iterations/07-voice-waveform-and-motion.md) обновляет RMS-шкалу записи (окна по 50 мс), оттенок плеера, цвета собственных голосовых в списке, отступы времени и шапки до краёв окна. Общие переходы панелей/окон/страниц — около 180 мс, с поддержкой уменьшения движения. Проверки: `flutter test test/voice_waveform_test.dart test/app_motion_test.dart test/conversation_list_test.dart`. [Снимки и ограничения проверки](../../docs/design/mobile-refresh/voice-update/index.html).

## Демонстрация экрана (экспериментальная)

Клиент использует отдельный ScreenShareController текущего VoiceCall и существующие
Matrix/LiveKit подключения. ScreenCapture подготавливается из пользовательского
нажатия до claim; ключи идут только encrypted Matrix to-device. В UI есть отдельный
screen view, takeover/stop/fullscreen и Auto/Low. Server capability по умолчанию off.
[Инструкция](../../docs/screen-sharing.md), [матрица приёмки](../../docs/screen-sharing-acceptance.md).
Android service подготовлен, аппаратная проверка отложена; mobile web в закреплённом
SDK имеет только просмотр. Не включать функцию в релиз по одному успешному build.

## Регистрация в браузере

«Создать аккаунт» открывает форму без предварительного открытия локального хранилища. Пользователь задаёт пароль аккаунта и подтверждает почту. Имя профиля и ключ шифрования браузерной базы создаются автоматически. После регистрации приложение создаёт E2EE identity и резервную копию ключей, показывает аварийный ключ восстановления. При выходе с незавершённой формы клиент закрывается. Проверка: `flutter test test/registration_screen_test.dart` и `node prototype/check_signup_ui.cjs` из корня с Playwright в NODE_PATH.
